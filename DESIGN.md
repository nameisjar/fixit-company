# FIXIT — DESIGN SYSTEM

> Design specification for the FIXIT Technology Solutions website.
>
> This document is the visual source of truth for the FIXIT website.
> All frontend UI implementation must follow this document unless a newer explicit design decision replaces it.

---

# 1. Brand Identity

## Brand Name

FIXIT

## Legal / Full Name

PT FIXIT Solution Technology

## Tagline

> Your Technology, Our Solution.

## Brand Positioning

FIXIT is a technology solutions company that helps individuals, businesses, organizations, and institutions solve practical technology needs.

Core services include:

- CCTV installation
- Starlink installation
- Network and Wi-Fi installation
- Website development
- Application development
- IT support
- Computer and device maintenance
- Custom technology solutions

The visual identity must communicate:

- Technology
- Reliability
- Engineering
- Professionalism
- Practicality
- Connectivity
- Modernity

---

# 2. Logo Reference

The provided FIXIT logo is the primary visual reference.

The logo contains:

1. FIXIT wordmark
2. Blue-to-cyan technology gradient
3. Dark charcoal elements
4. Orbital/connection symbol
5. Pixel/square elements
6. "SOLUTION TECHNOLOGY" descriptor
7. "Your Technology, Our Solution." tagline

The website must visually complement the logo instead of competing with it.

---

# 3. Brand Personality

The website should feel:

- Modern
- Technical
- Professional
- Reliable
- Clean
- Confident
- Approachable
- Practical

The website should NOT feel like:

- An AI startup landing page
- A cryptocurrency website
- A gaming website
- A futuristic sci-fi interface
- A generic SaaS template
- An overly formal corporate website
- A generic digital agency template

The core visual idea is:

> Technology that solves real problems.

---

# 4. Core Design Principle

Use:

> **Technical visual language + human usability**

The website should look technically capable while remaining easy for a non-technical customer to understand.

Priority order:

1. Clarity
2. Trust
3. Usability
4. Brand consistency
5. Performance
6. Visual effects

Never sacrifice usability for decorative visual effects.
